# Metroway v1.8.0 - Performance & UI Polish 🚇

This release introduces significant UI refinements and performance optimizations to make your Delhi Metro navigation smoother and more intuitive.

## 🚀 Key Improvements

### 💎 Premium UI Redesign
- **Ultra-Compact Home Screen:** Reclaimed valuable vertical space by streamlining the header and tightening interaction cards. More information is now visible at a glance.
- **Unified Branding:** Seamless color integration between the Status Bar and App Header for a polished, high-end look.
- **Floating Journey Panel:** Redesigned the draggable bottom sheet with a modern "floating card" aesthetic, featuring rounded corners and optimized widths.

### ⚡ Performance & Reliability
- **Smooth Animations:** Integrated native driver support for the bottom sheet, ensuring 60fps responsiveness during gestures.
- **Intelligent Clamping:** Fixed accessibility issues by locking the slider to a safe range, preventing it from obscuring system controls.
- **Optimized Routing:** Implemented memoization across the timeline and search components, resulting in zero-lag interaction even on long transit routes.

### 📊 Real-Time Intelligence
- **Dynamic Network Stats:** The footer now displays live station counts and system status directly from the transit graph.
- **Smart History:** Improved recent journey logic to prevent duplicate entries and keep your history clean.
