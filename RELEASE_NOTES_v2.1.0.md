# Metroway v2.1.0 - Real-Time Intelligence & Compact Navigation 🚇

This update brings live DMRC service alerts and further UI refinements for an even more efficient navigation experience.

## ✨ What's New

### 📡 Live DMRC Integration
- **Real-Time Alerts:** Replaced placeholder warnings with live data directly from the official DMRC Status API. Get instant updates on snags, delays, and planned maintenance across all lines.
- **Dynamic Network Status:** View live network-wide conditions and line-specific announcements.

### 📐 Compact Navigation UI
- **Slimmer Navigation Bar:** Adjusted the bottom tab bar and icon sizing to reclaim vertical space, making the main content area feel more spacious.
- **Tighter Bottom Inset:** Optimized the layout for Android devices to eliminate dead space at the bottom of the screen.
- **Improved Hierarchy:** Fine-tuned font sizes and paddings in the tab bar for better readability and a more professional look.

### 🐛 Performance & Reliability
- **Optimized Scrolling:** Reduced Home screen padding to allow more information to be visible without scrolling.
- **Fixed Slider Accessibility:** Further refinements to the bottom sheet to ensure the handle remains perfectly reachable on all screen sizes.
